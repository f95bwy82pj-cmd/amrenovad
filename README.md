# amrenovad

## VK Реклама: статистика и отчёты

Утилита `vkads` выгружает статистику из кабинета [VK Рекламы](https://ads.vk.com) через API
и собирает отчёты: CSV для Excel или Google Таблиц и HTML-страницу с итогами, графиком расхода и таблицами.

### Подключение кабинета

1. В кабинете ads.vk.com откройте **Настройки → Доступ к API** и получите `client_id` и `client_secret`.
   Если доступа к API ещё нет, там же можно оставить заявку.
2. Скопируйте `.env.example` в `.env` и вставьте ключи:
   ```
   VK_ADS_CLIENT_ID=...
   VK_ADS_CLIENT_SECRET=...
   ```
   Для агентского кабинета добавьте `VK_ADS_AGENCY_CLIENT_NAME` — логин клиента.
3. Установите и проверьте:
   ```bash
   pip install -e .
   vkads check
   ```

Файл `.env` и кэш токена `.vkads_token.json` в git не попадают.

### Команды

```bash
vkads list                                  # кампании
vkads list --level ad_groups                # группы объявлений (или banners — объявления)

vkads report                                # последние 7 дней по кампаниям, CSV + HTML в ./reports
vkads report --days 30 --level banners      # 30 дней по объявлениям
vkads report --from 2026-10-01 --to 2026-10-31 --format html
```

Отчёт `report` создаёт три файла:

- `*_daily.csv` — по дням и объектам;
- `*_summary.csv` — итоги по каждому объекту и общий итог;
- `*.html` — сводка: расход, показы, клики, конверсии, CTR, CPC, CPA, график по дням.

Показатели: показы, клики, расход, конверсии (цели), CTR, CPC, CPM, CPA, CR.
Производные метрики пересчитываются из сумм, поэтому итоги за период корректны.

### Лимит токенов

VK Реклама ограничивает число активных токенов на одно приложение. Утилита хранит токен
в `.vkads_token.json` и продлевает его через refresh token. Если всё же появилась ошибка
о превышении лимита, выполните:

```bash
vkads tokens-reset
```
